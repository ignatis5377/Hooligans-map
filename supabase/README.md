# Οδηγίες Ρύθμισης Backend (Supabase)

Το **Supabase** είναι η δωρεάν cloud βάση δεδομένων και αποθηκευτικός χώρος για τις φωτογραφίες σας.

---

## Βήμα 1: Δημιουργία Δωρεάν Project στο Supabase

1. Μπείτε στο [supabase.com](https://supabase.com) και συνδεθείτε ή κάντε δωρεάν εγγραφή (Sign Up).
2. Πατήστε **"New Project"**.
3. Επιλέξτε ένα όνομα (π.χ. `hooligans-map`) και έναν ισχυρό κωδικό βάσης (Database Password).
4. Επιλέξτε περιοχή (Region: π.χ. `Frankfurt (eu-central-1)` για μέγιστη ταχύτητα στην Ελλάδα).
5. Πατήστε **"Create new project"** (θα χρειαστούν ~1-2 λεπτά για να ετοιμαστεί).

---

## Βήμα 2: Εκτέλεση του SQL Schema

1. Στο αριστερό μενού του Supabase, πατήστε **SQL Editor** (το εικονίδιο με το `>_`).
2. Πατήστε **"New Query"**.
3. Αντιγράψτε όλο το περιεχόμενο του αρχείου `supabase/schema.sql` και επικολλήστε το στον SQL Editor.
4. Πατήστε **"Run"** (Ctrl+Enter).
5. Θα δείτε το μήνυμα `Success. No rows returned`. Ο πίνακας `photos` και οι πολιτικές ασφαλείας έχουν δημιουργηθεί!

---

## Βήμα 3: Δημιουργία του Storage Bucket

1. Στο αριστερό μενού, πατήστε **Storage**.
2. Πατήστε **"New Bucket"**.
3. Στο πεδίο **Bucket Name** γράψτε ακριβώς: `photos`
4. **ΣΗΜΑΝΤΙΚΟ:** Ενεργοποιήστε τον διακόπτη **"Public bucket"** (ώστε οι φωτογραφίες να είναι ορατές στον δημόσιο χάρτη της ιστοσελίδας).
5. Πατήστε **"Save"**.

---

## Βήμα 4: Δημιουργία του Admin Λογαριασμού σας

1. Στο αριστερό μενού, πατήστε **Authentication** -> **Users**.
2. Πατήστε **"Add User"** -> **"Create User"**.
3. Βάλτε το Email σας και έναν ασφαλή κωδικό (Password).
4. Βεβαιωθείτε ότι είναι τσεκαρισμένο το **"Auto Confirm User"** και πατήστε **"Create User"**.
> *Με αυτά τα στοιχεία θα συνδέεστε στην εφαρμογή του κινητού σας.*

---

## Βήμα 5: Αντιγραφή των API Keys

1. Στο αριστερό μενού, πατήστε **Project Settings** (το γρανάζι κάτω αριστερά) -> **API**.
2. Αντιγράψτε τα εξής 2 στοιχεία:
   * **Project URL** (π.χ. `https://abcdefghijkl.supabase.co`)
   * **Project API Keys** -> `anon` / `public` key (μια μεγάλη σειρά χαρακτήρων)
3. Αυτά τα 2 στοιχεία θα τα επικολλήσετε:
   * Στο αρχείο `web-widget/config.js`
   * Στο αρχείο `mobile-app/src/config/supabase.js`
