# Οδηγίες Εκτέλεσης: Mobile App (React Native / Expo)

Η εφαρμογή σας επιτρέπει να τραβάτε φωτογραφίες με την κάμερα ή να επιλέγετε από τη συλλογή, καταγράφει αυτόματα το ακριβές στίγμα GPS, συμπιέζει αυτόματα την εικόνα και την ανεβάζει στον χάρτη της ιστοσελίδας σας.

---

## 🛠️ Προαπαιτούμενα

1. **Node.js (LTS)**:
   * Αν δεν το έχετε ήδη εγκατεστημένο, μπορείτε να το εγκαταστήσετε ανοίγοντας το PowerShell ως Διαχειριστής και γράφοντας:
     ```powershell
     winget install OpenJS.NodeJS.LTS
     ```
   * Ή κατεβάστε το από το [nodejs.org](https://nodejs.org).
2. **Εφαρμογή Expo Go στο κινητό σας**:
   * [Expo Go για Android (Google Play)](https://play.google.com/store/apps/details?id=host.exp.exponent)
   * [Expo Go για iOS (App Store)](https://apps.apple.com/app/expo-go/id982107779)

---

## 🚀 Βήματα Εκτέλεσης

### Βήμα 1: Ρύθμιση των Supabase Keys
Ανοίξτε το αρχείο `mobile-app/src/config/supabase.js` και συμπληρώστε το **Project URL** και το **Anon Key** από το Supabase dashboard σας:

```javascript
export const SUPABASE_URL = 'https://YOUR_SUPABASE_PROJECT_ID.supabase.co';
export const SUPABASE_ANON_KEY = 'YOUR_SUPABASE_ANON_KEY';
```

### Βήμα 2: Εγκατάσταση Πακέτων
Ανοίξτε ένα τερματικό (PowerShell ή Command Prompt) στον φάκελο `mobile-app`:

```bash
cd "d:\Lesvos MTB\Hooligans\mobile-app"
npm install
```

### Βήμα 3: Εκκίνηση της Εφαρμογής
Εκτελέστε την εντολή:

```bash
npx expo start
```

### Βήμα 4: Άνοιγμα στο Κινητό σας
1. Στην οθόνη του υπολογιστή σας θα εμφανιστεί ένα μεγάλο **QR Code**.
2. **Σε Android:** Ανοίξτε την εφαρμογή **Expo Go** και πατήστε *"Scan QR Code"*.
3. **Σε iPhone:** Ανοίξτε την προεπιλεγμένη εφαρμογή **Κάμερα** και σκανάρετε το QR code (θα εμφανιστεί ειδοποίηση για άνοιγμα στο Expo Go).
4. Η εφαρμογή θα φορτώσει απευθείας στο κινητό σας!

---

## 📱 Χρήση της Εφαρμογής

1. **Σύνδεση:** Κάνετε login με το Email και Password που δημιουργήσατε στο Supabase Authentication (Βήμα 4 του `supabase/README.md`).
2. **Λήψη Σημείου:**
   * Πατήστε **"📸 Λήψη Φωτογραφίας"** ή **"🖼️ Από Συλλογή"**.
   * Το GPS θα εντοπίσει αυτόματα τις συντεταγμένες και την ακρίβεια (π.χ. `±3m`).
   * Προσθέστε προαιρετικά Τίτλο και Περιγραφή.
   * Πατήστε **"📍 Ανάρτηση στον Χάρτη"**.
3. **Διαχείριση Σημείων:**
   * Στην καρτέλα **"📋 Όλα τα Σημεία"** μπορείτε να δείτε όλα τα σημεία που έχετε ανεβάσει και να διαγράψετε όποιο δεν χρειάζεστε.

## 📦 Δημιουργία Αυτόνομου Android APK (Χωρίς Expo Go)

Για να έχετε την εφαρμογή εγκατεστημένη μόνιμα στο Android κινητό σας (με δικό της εικονίδιο στην αρχική οθόνη και χωρίς να επηρεάζεται από αναβαθμίσεις του Expo Go):

1. **Δωρεάν Λογαριασμός Expo:**
   * Αν δεν έχετε, φτιάξτε έναν δωρεάν λογαριασμό στο [expo.dev/signup](https://expo.dev/signup).
2. **Εκκίνηση Κατασκευής APK:**
   * Κάντε διπλό κλικ στο αρχείο [build-apk.bat](file:///d:/Lesvos%20MTB/Hooligans/mobile-app/build-apk.bat).
   * Συνδεθείτε με τα στοιχεία σας στο Expo.
   * Το **EAS Build** θα δημιουργήσει το αρχείο `.apk` στο Cloud.
3. **Εγκατάσταση στο Κινητό:**
   * Μόλις τελειώσει η κατασκευή, θα εμφανιστεί στην οθόνη ένα **QR Code** και ένα **Download Link**.
   * Σκανάρετε το QR code από το κινητό σας ή ανοίξτε το link στον browser του κινητού για να κατεβάσετε και να εγκαταστήσετε το **Hooligans Map APK**!
